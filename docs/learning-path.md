# Java 后端学习路线

> 按“学会概念 → 写最小代码 → 运行验证 → 在实际项目应用”推进；不是必须一次学完所有专题。

## 第 1 阶段：核心 Java

- 变量与类型、流程控制、数组、字符串、方法
- 类与对象、接口、继承、多态、异常
- List / Set / Map、泛型、迭代器、Stream
- **验收：** 能独立解释并运行 [WordFrequencyDemo](../core-java/README.md)，尝试添加空输入与重复词边界用例

## 第 2 阶段：运行机制和并发

- JVM 内存模型（运行时数据区）、类加载、GC 概念
- 线程、锁、线程池、`volatile`、`synchronized`、`CompletableFuture`
- 文件 IO、NIO、连接超时和资源释放
- **验收：** 用一个可运行的实验演示竞态条件及修复方案，记录结果

## 第 3 阶段：Spring Boot

- Maven 项目结构、依赖管理、自动配置与依赖注入
- Controller / Service / Repository 分层、参数校验、统一异常处理
- 单元测试与接口测试、日志和配置管理
- **验收：** 编写并测试一个最小 CRUD REST API

## 第 4 阶段：数据与工程实践

- 事务边界、错误处理、幂等和重试
- 数据库连接池、SQL 与索引、Redis 缓存
- 认证授权、可观测性、Docker 部署
- **验收：** 给 API 补上数据库与测试，解释数据一致性策略

MySQL 等独立实验维护在 [database-lab](https://github.com/sorenjing/database-lab)，不在这里复制学习笔记。

## 学习记录模板

每次实验附上：

- **问题：** 想验证什么？
- **环境：** JDK / 框架 / 数据库版本
- **步骤：** 运行命令和测试输入
- **观察：** 实际结果、失败与日志
- **结论：** 哪些得到验证，哪些仍是假设？
